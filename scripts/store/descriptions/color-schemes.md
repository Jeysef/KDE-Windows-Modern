Windows 11's colors for KDE Plasma 6: **Windows Modern Dark** and **Windows Modern Light** color schemes, with Windows' blue accent.

Choose them in *System Settings → Colors & Themes → Colors*.

Part of [Windows Modern](https://github.com/Jeysef/KDE-Windows-Modern), a Windows 11 look and feel for Plasma 6; the Windows Modern global themes install these automatically. Based on Win11OS-kde by yeyushengfan258. License: GPL-3.0.
