A **Windows 11-style clock** for the Plasma 6 panel: time above date, sized like Windows', and a calendar flyout with today highlighted and event dots from your KDE calendars.

It keeps Plasma's clock settings: time and date formats, time zones and calendar plugins.

Add it with *Add Widgets → Windows Modern Digital Clock*.

Part of [Windows Modern](https://github.com/Jeysef/KDE-Windows-Modern), a Windows 11 look and feel for Plasma 6; the Windows Modern global themes install it automatically. License: GPL-3.0.
